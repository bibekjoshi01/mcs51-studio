MCS51 Studio v0.2.2 fixes application shutdown and improves Windows setup.

## Changes

- Fix the “Tk object is not callable” crash when closing the application or processing virtual-board events.
- Preserve other panels’ scroll handlers when a scrollable panel closes.
- Show installation-folder and Start-menu-folder choices on Windows, with an optional desktop shortcut. Installation remains per-user by default.
- Exercise the visible virtual board and normal application close path in every frozen-app smoke test. Add repeated widget teardown regression coverage.
- Test installation into a custom Windows folder, launch the installed application, verify clean shutdown, and run the uninstaller in CI.

Install v0.2.2 to replace v0.2.1. Save your work and close the old application first.
Choose `*-windows-x64-setup.exe` on Windows; `.sha256` files are optional checksums.

These packages are not production-signed or notarized.
