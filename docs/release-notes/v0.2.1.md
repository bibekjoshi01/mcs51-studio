MCS51 Studio v0.2.1 is a QA and reliability patch candidate.

## Corrections

- Preserve operand expressions, HIGH/LOW, and whitespace; resolve forward EQU aliases before emitting code. Reject circular dependencies, uninitialized SET variables, negative addresses, and out-of-range branches.
- Validate Intel HEX record shapes and bound assembler resource use. Large symbol tables and full-memory exports avoid unnecessary repeated work.
- Preserve motor timing remainders across update intervals. Shared-pin display/DAC consumers and UART pin levels now reflect the resolved state in the same update.
- Refresh only affected listing rows, reuse reference/mapping windows, and pause execution before opening documents.
- Fix a long-UART-line freeze with horizontal scrolling and no forced scrolling of hidden terminals. Bound serial histories, transcript size, and activity retention.
- Recover safely from malformed settings and write settings atomically.
- Install macOS upgrades explicitly in Applications, without relocating to another app copy; replace obsolete bundle files on upgrade.

## QA Coverage

The headless suite contains 108 tests, including exhaustive CPU arithmetic checks,
1,000 generated programs with independently calculated bytes/results, 3,000 mutated
inputs, 10,000-symbol assembly, a full 64 KB HEX round trip, a 50,000-instruction
LED/debugger soak, elapsed-time motor invariance, and timer-driven UART programs.
Desktop coverage includes the existing 20 integration tests plus seven stress tests:
1,000 control actions, all 41 main menu commands, keyboard shortcuts, tool-window
cycles, a 65,536-row listing, output retention, and file failure/cancellation paths.
The stress suite now runs in CI and installer jobs.

## Distribution Status

This is a candidate, not a claim of production certification. Windows/Linux native
installer runs, clean-machine install/upgrade/uninstall checks, and production
signing/notarization must pass before public distribution. Simulation boundaries
remain documented in the supported-features guide; sub-instruction electrical
behavior and reverse stepping are not modeled.
