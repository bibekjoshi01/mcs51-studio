MCS51 Studio v0.2.3 improves editor layout, execution controls, memory editing,
and virtual-board workflows, with acceptance tests based on the EdSim51 guide.

## Fixes

- Stop execution when the next address has no loaded code, preserving final
  registers and results for inspection. Reset starts the program again.
- Keep the editor status row visible at larger text sizes, including with search
  and diagnostic panels open.
- Correct the keypad interrupt gate so idle rows do not cause false INT1 requests.
- Stop before a breakpoint on the first instruction and resume correctly.
- Preserve edited machine bytes in Intel HEX exports, including newly added code
  regions. Mark modified bytes in Listing and avoid misleading source descriptions.
- Validate batch sizes and memory navigation addresses; add horizontal memory scrolling.
- Release the UART transmit pin immediately when resetting a paused link.
- Remember the last file-dialog directory and include `.a` assembly files.
- Align the motor graphic with its sensor and improve LCD symbols/configuration hints.

## Added Controls

- Inspect and edit all implemented SFRs, with register-address hints and a bitfield
  that allows editing only bit-addressable bytes.
- Toggle breakpoints by address or clear them all from Listing.
- Enter custom batch sizes, including 50,000, and retain the applied setting.
- Adjust motor speed and enable simulated-time keypad bounce in Standard mode.
  Standard is now the default keypad mode; Pulse and Radio remain available.
- Retain experiment settings and UART framing across sessions. Existing projects
  without the new optional bounce/speed settings remain readable.

## Validation And Scope

The source checks cover 128 unit/integration tests, 37 GUI acceptance tests, and
7 stress tests. The guide GUI suite now runs in normal CI and native release builds.
See the [guide acceptance review](https://github.com/bibekjoshi01/mcs51-studio/blob/v0.2.3/docs/guide-acceptance.md)
for coverage and known differences. This release does not claim full EdSim51 parity:
custom board colors/key labels, arbitrary clocks, and the full LCD character ROM
remain unsupported.

## Install Or Upgrade

Save your work and close MCS51 Studio before installing v0.2.3 over v0.2.2.
Choose the installer matching your operating system and processor:

- Windows x64: `MCS51-Studio-0.2.3-windows-x64-setup.exe`
- macOS Apple Silicon: `MCS51-Studio-0.2.3-macos-arm64.pkg`
- macOS Intel: `MCS51-Studio-0.2.3-macos-x64.pkg`
- Linux amd64: `MCS51-Studio-0.2.3-linux-amd64.deb`
- Linux arm64: `MCS51-Studio-0.2.3-linux-arm64.deb`

Each installer has a corresponding `.sha256` checksum. Packages are not
production-signed or notarized.
