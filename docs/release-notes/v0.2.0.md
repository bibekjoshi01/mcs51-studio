MCS51 Studio v0.2.0 adds explanatory debugging, configurable teaching peripherals, and portable experiment projects.

## Debugger That Explains Execution

- Step Over (F8), Step Out (Shift+F8), and Run To Cursor (F9), with tracked calls and interrupts.
- Register, flag, RAM, SFR, code, and external-memory watches; break when a watched value changes.
- A stack view, changed-register highlighting, and last-instruction inputs, results, flags, memory changes, and cycle costs.
- Clear stops for mismatched returns and unreached execution targets.

## Better Peripheral Experiments

- Standard, Pulse, and Radio keypad modes, with visible key states.
- Optional deterministic switch bounce and configurable INT0/INT1 pulses.
- LCD cursor, blinking, programmable 5×8 characters, busy timing, and ignored-write diagnostics.
- UART controls for 7/8 data bits, parity, and 1/2 stop bits, with start/parity/framing errors and safe handling of invalid input.
- Focused Experiment Settings controls keep the main workbench compact.

## Portable Projects And Recovery

- Save a complete experiment as one `.mcs51` file: assembly source, processor/clock profile, wiring, enabled devices, inputs, teaching settings, UART framing, watches, and analyzer probes/triggers.
- Restore the same configuration on another machine without external source files or absolute paths.
- Autosave recovery every 15 seconds, atomic writes, and validation that rejects unsupported or malformed settings before replacing the open experiment.

## Validation

- 95 headless tests and 20 macOS desktop integration tests passed during development.
- Coverage includes nested/recursive calls, interrupt returns, change breakpoints, project round trips, invalid files, failed saves, keypad modes, bounce/pulse timing, LCD busy boundaries, and every supported UART framing combination.
- The release workflow tests and smoke-checks native builds before attaching installers and SHA-256 checksums.

## Installation And Current Limits

Choose the installer matching your platform: Windows x64, macOS Apple Silicon/Intel, or Debian/Ubuntu amd64/arm64. Installers bundle the runtime.

This is a draft for release validation. Default installers are not production-signed or Apple-notarized; clean-machine installation, upgrades, and OS trust checks remain necessary before public publication.

- The supported processor remains Classic 8051 at 12 MHz, with 12 clocks per machine cycle.
- Measurements and change breakpoints observe instruction boundaries; sub-instruction electrical behavior is not modeled.
- Projects preserve experiment configuration, not paused CPU state, serial queues, or captured waveforms.
- Execution history and reverse stepping remain planned.
