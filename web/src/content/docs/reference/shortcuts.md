---
title: Keyboard shortcuts
description: Essential file, editor, debugger, and layout shortcuts for MCS51 Studio.
---

Use **Command** on macOS wherever **Ctrl** is shown, except completion, which uses Control+Space. Function keys may need **Fn**, depending on keyboard settings. Press **F1** in the app for its shortcut reference.

## Assemble and execute

- **F6:** Assemble.
- **F7:** Step one instruction.
- **F5:** Run or pause.
- **F8:** Step Over.
- **Shift+F8:** Step Out.
- **F9:** Run To Cursor.
- **Shift+F5:** Reset machine state.

## Files

- **Ctrl+N:** New.
- **Ctrl+O:** Open.
- **Ctrl+S:** Save the current source or project.
- **Ctrl+Shift+S:** Save As.

## Editing

- **Ctrl+Z:** Undo.
- **Ctrl+Shift+Z:** Redo. Ctrl+Y also works in the editor.
- **Ctrl+X / C / V / A:** Cut, Copy, Paste, Select All.
- **Ctrl+/:** Toggle comments.
- **Ctrl+D:** Duplicate lines.
- **Ctrl+Shift+K:** Delete lines.
- **Alt+Up / Alt+Down:** Move lines.
- **Tab / Shift+Tab:** Indent or unindent.
- **Ctrl+Space:** Complete an instruction or symbol; **Control+Space** on macOS.

## Find and navigate

- **Ctrl+F:** Find and replace.
- **Ctrl+H:** Also opens Find/Replace on Windows and Linux.
- **Command+Option+F:** Also opens Find/Replace on macOS.
- **Escape:** Close search controls.
- **Ctrl+G:** Go to line.

## Layout and readability

- **Ctrl+J:** Toggle bottom tools.
- **Ctrl++ / Ctrl+-:** Increase or decrease editor text size.
- **Ctrl+0:** Reset editor text size.
- **F1:** Show shortcut reference.

Use **View → Reset Layout** to restore pane sizes and visibility. The **Focus Editor** control hides or restores supporting panels.

## Website shortcuts

These apply to this documentation site, separately from the desktop app:

- **Ctrl+K / Command+K:** Open documentation search.
- **Escape:** Close search.
- **Tab / Shift+Tab:** Move between links and controls.

Search is generated during the production build. When developing the website, build and preview it to test the full search index.
